Reading the numbers

Decompiled describes the published code target. Linked is a separate measure.

A 100% code report does not establish asset, port or gameplay completion. Claims and function counts retain their own labels.

Builds and tests have not been verified by this library. Tools and related projects have no comparable game decompilation percentage.
